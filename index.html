Mes réalisations

Je prépare ma carrière de développeurs dans le but de concevoir des outils permettant de simplifier et automatiser le travail. Ci dessous se trouve un apperçu de quelques outils que j'ai développé et que j'utilise de temps en temps. Dont un projet C++ en cours de développement.

Chatbot PyTorch

Je cherchais à comprendre comment le code des IA fonctionne.

La meilleure façon de comprendre comment fonctionne un programme est de le créer.

J'ai installé et utilisé les bibliothèques PyTorch pour le cerveau et Tkinter pour l'interface.

Récupérateur de clé WiFi

Oublier un mot de passe WiFi et tenter de le retrouver peut devenir dérangeant.

Il m'a fallu trouver une manière d'automatiser la récupération du mot de passe.

La solution est de créer script qui ouvre automatiquement un terminal et éxécute les commandes nécessaires..

Moniteur GPU

Le gestionnaire de tâches par défaut de Linux ne surveille pas le GPU.

L'objectif est de créer mon propre logiciel dédié.

Pour cela il a fallu automatiser l'éxécution de commandes "nvidia-smi" et afficher les informations à surveiller dans une interface Tkinter.
